# 路线图

以"可交付、可验收"为粒度。每个阶段结束时代码可运行、可部署、可演示。

## P0 · MVP（目标：单站点可运营）

### 后端

- [x] 工程基线：monorepo 骨架、pnpm workspace、mise 工具链、ESLint（better-tailwindcss）、CI
- [x] `packages/contracts`：zod schema + OpenAPI 生成 + 权限点定义（24 个权限点）
- [x] 数据模型：Drizzle schema（33 表 / 28 枚举）、迁移、种子数据
- [x] 认证：登录 / 登出 / 会话 / RBAC（注册、邮箱验证码、2FA 待做）
- [ ] RBAC：`requirePermission` 中间件 + 权限点校验
- [x] 商品：CRUD、上下架、库存（用户端 + 管理端）
- [x] 订单：创建、查询、取消、手动完成、状态机（支付回调待做）
- [ ] 支付：内置易支付插件（创建支付、回调验签、幂等）
- [x] 订阅：配额判定、渲染（v2ray / clash / sing-box）、订阅输出路由、用户端页面
- [x] 节点：CRUD、节点组、证书、内核配置渲染（sing-box / xray）
- [x] Agent 协议：契约 + HMAC 签名（4 组跨端测试向量）
- [ ] 流量：内存计数 + 批量落库 + 汇总
- [ ] 定时任务：流量刷入、订单过期、订阅到期、节点健康
- [~] 审计日志、登录日志、任务日志（表已建，写入待接）

### 前端

- [ ] Nuxt UI 集成、主题（主色/中性色）、明暗模式、图标本地化
- [ ] i18n：`zh-CN` + `en`，`no_prefix` 策略，语言切换器
- [ ] 布局：默认页 / 认证页 / 用户端 / 管理端
- [ ] 导航：菜单（权限过滤）、命令面板、快捷键、面包屑
- [ ] 认证页：登录、注册、找回密码
- [ ] 用户端：概览、商品、下单、订单、订阅、流量、个人设置
- [ ] 管理端：仪表盘、商品、订单、订阅、节点、用户、日志、系统设置
- [ ] 通用组件：DataTable、StateBadge、QuotaBar、CopyButton、EmptyState

### Agent

- [x] 配置解析、注册、HMAC 签名、心跳
- [x] 拉取配置并应用（sing-box）、内核进程守护
- [x] 流量采集与上报、差值与幂等
- [ ] systemd 单元、安装脚本、基础日志

### 验收标准

- 完整跑通：注册 → 下单 → 支付 → 拿到订阅链接 → 客户端能连上节点 → 流量出现在面板
- 面板不可达时，节点继续服务（缓存配置）
- `pnpm typecheck` / `lint` / `test` 全绿
- OpenAPI 契约漂移检测在 CI 生效
- Agent 签名与面板 canonical 一致（共享测试向量通过）

## 里程碑顺序与并行策略

```
P0-1  contracts + schema + auth + RBAC     ← 主干（主会话）
P0-2  商品/订单/支付/订阅 + 前端页面        ← 可并行：后端接口 / 前端页面 / 订阅渲染器
P0-3  节点 + Agent 协议 + Agent CLI         ← 可并行：面板节点模块 / Go CLI / 配置渲染器
P0-4  集成、联调、压测、部署脚本            ← 主会话
```

并行派发时的文件所有权划分见 [frontend-architecture §9](frontend/frontend-architecture.md#9-契约变更流程) 与 ADR-0001 的依赖方向约束。

## 风险登记

| 风险 | 影响 | 缓解 |
|---|---|---|
| Agent 与面板签名不一致 | 全部节点失联 | 共享测试向量 + CI 契约测试 |
| 内核配置渲染错误 | 用户连不上 | 配置下发前 JSON 校验 + Agent 侧保留旧配置回滚 |
| 支付回调重复 | 重复开通 | 幂等约束 + 状态机校验 |
| 流量丢失 | 用户配额不准 | 进程内计数 + Agent 本地缓冲补报（seq 幂等） |
| 插件拖垮面板 | 全站不可用 | 超时 + 熔断 + 外置进程 |
| 面板与 Agent 版本不匹配 | 通信失败 | `minAgentVersion` + 灰度升级 |
